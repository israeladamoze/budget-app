# תקציב הבית

אפליקציית תקציב משותפת לזוג – מעבר דירה והוצאות שוטפות. קובץ HTML אחד שעובד בטלפון וניתן להתקנה למסך הבית (PWA).

- **מעבר דירה** – רשימת קניות לפי חדרים עם תקציב מול מחיר בפועל, הוספה / "לא צריך" / שחזור / מחיקה, צ׳קליסט העברת חשבונות, קריאת מונים ופיקדונות.
- **חשבונות קבועים** – שכר דירה, ארנונה, מים, חשמל, גז, ועד בית ועוד; "שולם" רושם את התשלום ומקדם את החיוב הבא.
- **חשבון משותף** – כמה כל אחד מעביר החודש (חצי מהחשבונות הקבועים + תקציב משתנות), מעקב העברות ויתרה.
- **הוצאות** – הוספה מהירה, מי שילם, אמצעי תשלום, תשלומים והערה לכל הוצאה; חיפוש וסינון.
- **דוחות** – לפי קטגוריה, מגמה, תכנון מול בפועל, תחזית, איזון 50/50.
- **ייצוא לאקסל** – גיליונות הוצאות, מעבר דירה, חשבונות קבועים וסיכום (עם נוסחאות), וגם CSV.

הנתונים נשמרים במכשיר בלבד (localStorage). לשיתוף בין בני הזוג או מעבר טלפון: הגדרות ← שמירת גיבוי / שחזור מגיבוי.

## בדיקות

70 תסריטי בדיקה אוטומטיים מקצה לקצה (Playwright) בתיקייה `tests/`:

```
npm i -D playwright && npx playwright install chromium
node tests/run.js            # הכול
node tests/run.js "MOV|BIL"  # רק מודולים מסוימים
```

בדיקות האקסל משתמשות ב־Python עם openpyxl, ובדיקת חישוב הנוסחאות ב־LibreOffice.
