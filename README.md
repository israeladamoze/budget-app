# תקציב המעבר

אפליקציה לזוג לתכנון הציוד והתקציב למעבר דירה. קובץ HTML אחד שעובד בטלפון וניתן להתקנה למסך הבית (PWA).

- **בית** – כמה נשאר מתקציב המעבר, צפי כולל, התקדמות לפי שלבים, הבא בתור לקנייה, קניות אחרונות ו"מי חייב למי".
- **קניות** – רשימה לפי חדרים בשני שלבים (חובה מיד / בהמשך) ועלויות המעבר: תקציב מול מחיר בפועל, מי שילם, תשלומים, אחריות והערה. הוספה מרשימה או בהקלדה חופשית, "לא צריך" ושחזור.
- **משימות** – צ׳קליסט להעברת חשבונות ושינוי כתובת, וקריאת מונים ביום הכניסה.
- **פיקדונות** – פיקדון, ערבות או שטר חוב, בנפרד מהתקציב.
- **דוחות** – לפי חדר ושלב, קניות לפי חודש, תשלומי אשראי, וייצוא לאקסל (רשימת קניות, סיכום, פיקדונות) או CSV.

הנתונים נשמרים במכשיר בלבד (localStorage). לשיתוף בין בני הזוג או מעבר טלפון: הגדרות ← שמירת גיבוי / שחזור מגיבוי.

## בדיקות

48 תסריטי בדיקה אוטומטיים מקצה לקצה (Playwright) בתיקייה `tests/`:

```
npm i -D playwright && npx playwright install chromium
node tests/run.js            # הכול
node tests/run.js "MOV|BIL"  # רק מודולים מסוימים
```

בדיקות האקסל משתמשות ב־Python עם openpyxl, ובדיקת חישוב הנוסחאות ב־LibreOffice.
